# Start here

## What this part does

Use this as the café floor plan. Find the shop window, the manager's office, and the kitchen records in the order that fits your job.

## How it works, step by step

1. **Café owner.** Start with [admin access](ADMIN_ACCESS.md), then [the five-minute demo](report/14-owner-and-demo.md), [sample and real data](report/16-sample-and-real.md), and [verification](VERIFY_SUPABASE.md).
2. **Class 12 student.** Read [the welcome](report/01-overview.md), [the map](report/02-architecture.md), [the click-by-click story](report/05-flows.md), and [the database](report/06-database.md). Use [the glossary](report/glossary.md) and finish with [the quiz](report/quiz.md).
3. **Developer.** Read [the project index](../PROJECT_REPORT.md), [the file guide](report/03-file-guide.md), [setup](report/11-setup-and-deploy.md), then [testing](report/12-testing.md) and [the mobile audit](MOBILE_AUDIT.md).

## Which files are involved

| File | What it does in simple words |
|---|---|
| `PROJECT_REPORT.md` | The central index. |
| `docs/report/02-architecture.md` | The one-page café map. |

## What can go wrong and what to check

If a link in an older audit and a current chapter seem to disagree, check the status page and the dated evidence in the verification report.
